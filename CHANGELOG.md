# Changelog / 更新记录

## 1.2.2 — 2026-11-13

- Added a moving progress bar while Codex works and a filled green bar when the reply is complete.
  Codex 执行任务时显示滚动进度条，回复完成后显示满格绿条。
- Starting a new task clears the previous completion notice.
  新任务开始时自动收起上一次完成提示。

## 1.2.1 — 2026-11-13

- Finder, menu bar, and Touch Bar now share original artwork showing a finger tapping a control strip.
  Finder、菜单栏和触控条统一使用原创的“手指轻触触控条”图标。
- Clarified first launch from Applications and optional macOS login startup.
  补充从「应用程序」首次打开和设置登录启动的说明。

## 1.2.0 — 2026-11-13

First source-distribution package / 首个源码分发版本。

- Native Touch Bar companion with a GPT quota ring and a separate touch-hand menu icon.
  原生触控条助手，提供 GPT 额度环与手指轻触式菜单栏图标。
- Three-dot thinking animation, reply excerpts, and request-scoped Allow/Reject controls.
  三点思考动画、回复摘要，以及对应当前请求的 Allow/Reject 按钮。
- Foreground-aware placement and an optional login item.
  根据前台应用调整触控条位置，并可选择登录时启动。
- First-run chat setup; the public source contains no preselected personal chat.
  首次使用自行设置关注对话，公开源码不预置私人对话。
- Chinese and English READMEs, documented screenshots, build/test scripts and GitHub Actions.
  中英文 README、带说明的截图、构建与测试脚本，以及 GitHub Actions。
- Local ad hoc signing; no Developer ID signature or notarization in this package.
  本地 ad hoc 签名，本包未使用 Developer ID 签名或 Apple 公证。
